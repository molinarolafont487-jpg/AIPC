# Phantom AI Workstation 7天MVP规格说明

版本：V0.1  
状态：已确认核心技术决策，可进入开发计划拆解  
目标：用 7 天完成一条可演示的企业数字员工启动闭环

## 1. 产品定位

Phantom AI Workstation 是企业数字员工工作站。老板可以用自然语言指挥六个数字员工，并连接真人员工，在飞书等企业协同平台中完成任务协同、资料补充、结果生成、老板确认与任务归档。

第一周只验证一句话：

```text
老板可以用自然语言指挥六个数字员工，并让数字员工与真人员工协同完成一个真实企业任务。
```

## 2. 7天MVP最终闭环

```text
老板一句话下达任务
-> 系统生成任务卡
-> 分配六个数字员工
-> 通知真人员工补充资料
-> 真人员工在飞书回复
-> AI员工继续执行
-> 老板助理汇总结果
-> 老板确认
-> 任务归档到任务中心
```

## 3. 已确认决策

| 决策项 | 7天MVP选择 | 后续升级方向 |
| --- | --- | --- |
| 外部协同平台 | 飞书 | 钉钉、企业微信 |
| 认证基座 | 轻量内置账号体系 | Keycloak / SSO / LDAP / AD |
| 真执行数字员工 | 3个 | 6个全部真执行 |
| 向量能力 | PostgreSQL + pgvector | Qdrant / 混合检索 |
| Agent编排 | 轻量自研编排 | LangGraph / 更复杂工作流 |
| 部署方式 | 本地 Docker Compose | 企业私有化 / 混合云 |

## 4. 用户角色

| 角色 | 说明 | MVP权限 |
| --- | --- | --- |
| 老板 / 管理者 | 发起自然语言指令、确认结果 | 创建任务、确认任务、查看全部任务 |
| 真人员工 | 接收AI请求、补充资料 | 查看与自己相关的协同请求 |
| 系统管理员 | 配置用户、角色、飞书、模型 | 管理工作区配置 |
| 数字员工 | 执行任务、调用知识库、生成结果 | 由系统调度，不独立登录 |

## 5. 六个数字员工

| 数字员工 | 7天MVP状态 | 职责 |
| --- | --- | --- |
| 老板助理 | 真执行 | 结果汇总、老板简报、风险提醒、确认事项 |
| 销售助理 | 真执行 | 客户分析、跟进话术、方案生成、邮件草稿 |
| 知识库助理 | 真执行 | 资料检索、文档总结、证据引用、知识沉淀 |
| 运营助理 | 半自动 | 任务拆解、进度跟踪、执行闭环 |
| 内容助理 | 半自动 | PPT大纲、文案、短视频脚本 |
| 代码助理 | 半自动 | 小工具需求、代码原型、自动化脚本 |

半自动的含义：第一版可被任务卡分配、可展示执行状态、可输出模板化结果，但不要求复杂推理和完整工具调用。

## 7. 核心页面规格

### 7.1 AI指挥台

目标：让老板一进入系统就可以下达自然语言任务。

必须包含：

```text
自然语言输入框
快捷指令
六个数字员工状态
今日任务总览
真人员工待处理
AI请求补充
需要老板确认
运行记录
```

关键交互：

```text
输入自然语言
-> 点击生成任务卡
-> 查看解析结果
-> 修改字段
-> 确认执行
```

### 7.2 任务卡页面

必须展示：

```text

任务目标
任务类型

协作数字员工

预计输出结果
截止时间
风险提示
是否需要老板确认
```

## 8. Command Protocol

自然语言必须被解析为以下结构：

```json
{
  "task_title": "任务名称",
  "task_goal": "任务目标",
  "task_type": "任务类型",
  "primary_agent": "主责数字员工",
  "collaborating_agents": ["协作数字员工"],
  "human_collaborators": ["协作真人员工"],
  "input_sources": ["需要调用资料"],
  "expected_outputs": ["预计输出结果"],
  "deadline": "截止时间",
  "approval_required": true,
  "risk_level": "风险等级",
  "notification_channel": "飞书",
  "archive_location": "归档位置"
}
```

固定8类任务：

| 类型 | 默认分配对象 |
| --- | --- |
| 经营汇总 | 老板助理 |
| 任务拆解 | 运营助理 |
| 客户跟进 | 销售助理 |
| 资料检索 | 知识库助理 |
| 内容生成 | 内容助理 |
| 代码原型 | 代码助理 |
| 会议纪要 | 运营助理 + 知识库助理 |
| 多员工协同 | 老板助理 + 运营助理 |

## 9. 黄金Demo

用户输入：

```text
帮我准备明天下午给华星科技的合作方案，让销售小张补充预算，销售助理生成话术，内容助理生成PPT大纲。
```

系统生成任务卡：

```text
任务名称：华星科技合作方案准备
任务类型：客户跟进
主责数字员工：销售助理
协作数字员工：知识库助理、内容助理、老板助理
协作真人员工：销售小张
需要资料：客户资料、产品资料、历史方案
预计输出：客户分析、沟通话术、PPT大纲、邮件草稿
通知渠道：飞书
需要确认：是
```

完整演示步骤：

```text
1. 老板在AI指挥台输入任务
2. 系统生成任务卡
3. 老板确认执行
4. 销售助理启动任务
5. 知识库助理检索客户和产品资料
6. 系统通过飞书通知销售小张补充预算
7. 小张在飞书回复预算信息
8. 回复回流任务中心
9. 销售助理继续生成话术和跟进方案
10. 内容助理生成PPT大纲模板
11. 老板助理汇总一页确认版
12. 老板确认
13. 任务归档
```

| 幻影自用 | 幻影介绍、产品资料、数字员工介绍、商业模式、试点报价、合作方案、海报文案、视频脚本 | 产品介绍、PPT大纲、销售话术 |

验收要求：

```text
每套不少于10份文档
至少覆盖PDF/Word/PPT/Excel中的两类
知识库助理可以检索并引用
```

## 12. MVP验收标准

7天结束时必须现场演示：

| 验收项 | 通过标准 |
| --- | --- |
| 产品定位 | 一句话定位、菜单、六个数字员工固定 |
| 任务卡 | 自然语言能生成结构化任务卡 |
| Agent分配 | 任务能分配给主责Agent和协作Agent |
| 知识库 | 能检索Demo资料并显示引用 |
| 飞书协同 | 能通知真人员工，回复能回流任务中心 |
| 结果生成 | 能输出客户分析、话术、PPT大纲、老板确认版 |
| 老板确认 | 任务进入等待确认，确认后归档 |
| 企业基座 | 有轻量账号、角色、工作区隔离、审计日志 |
